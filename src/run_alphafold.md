# AlphaFold Server 操作步骤

## 工具信息
- 名称：AlphaFold Server (AlphaFold 3)
- 网址：https://alphafoldserver.com
- 访问日期：2026-09-28

## 输入
8 条多肽序列：LTVSPWY, ATVSPWY, LAVSPWY, LTASPWY, LTVAPWY, LTVSAWY, LTVSPAY, LTVSPWA

## 操作步骤
1. 登录 alphafoldserver.com
2. 点击 "New job"
3. 在 "Protein" 栏粘贴单条序列
4. Copies 设为 1，其他参数默认
5. 提交并等待，下载 PDB 文件，记录 pLDDT 分数
