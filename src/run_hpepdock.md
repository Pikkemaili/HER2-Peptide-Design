# HPEPDOCK 2.0 操作步骤

## 工具信息
- 网址：http://huanglab.phys.hust.edu.cn/hpepdock/
- 访问日期：2026-09-10

## 输入
- Receptor: data/6BGT.pdb
- Peptide: LTVSPWY (L肽) 和 LTVSAWY (L5肽)

## 操作步骤
1. Receptor 上传 6BGT.pdb。
2. Peptide 粘贴多肽序列。
3. Job name 填 L_vs_6BGT 和 L5_vs_6BGT。
4. 提交，等待结果，记录对接打分，下载复合物 PDB。

## 结果记录

- L5_vs_6BGT 对接打分：-198.400
